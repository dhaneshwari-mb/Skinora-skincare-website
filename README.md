# Skinora – Personalized Skincare App

## About the Project
Skinora is a skincare application designed to help users understand their skin type and follow personalized skincare routines. It provides skincare guidance, diet suggestions, and progress-tracking features to support consistent skincare habits.

## Features
- Skin type assessment
- Personalized morning, evening, and nighttime routines
- Food and hydration suggestions
- Skincare progress tracking
- Daily routine reminders
- Weekly and monthly skincare plans

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3

## Getting Started

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:
   ```bash
   cd Skinora
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

Note: The commands above assume your project uses React with Vite. Adjust them to match your actual setup.
